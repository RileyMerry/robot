# Robot Project

This repository contains the software for our Raspberry Pi robot project.

## Goals
- Set up a clean C++ development environment on Raspberry Pi
- Build a modular robot control system
- Support motor control, camera integration, and testing
- Use Git/GitHub for collaboration and version control

## Project Structure
- `src/` - C++ source files
- `include/` - header files
- `build/` - build output
- `scripts/` - helper scripts
- `docs/` - notes and documentation
- `tests/` - subsystem tests
- `logs/` - runtime logs
- `config/` - configuration files
